# PanPan Store 

Projeto educacional de uma loja virtual de artigos caninos e felinos.

## Tecnologias utilizadas
- HTML
- CSS
- PHP
- SQL (MySQL)

## Funcionalidades
- Exibição de produtos
- Organização por categorias (caninos e felinos)
- Layout de loja virtual

## Objetivo
Praticar conceitos de desenvolvimento web por meio da criação de um sistema de loja online.
